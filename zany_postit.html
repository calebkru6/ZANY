⚡ Ongoing Power — Badge Gap
  • Klaw and Iron Man don't emit power-delta floating badges — their bonus is computed dynamically in zonePower(), not via applyReveal(), so _snapshotPowers / _diffPowers never sees a .clout mutation. Zone scores show correct totals; per-card badges do not.
  • Fix path: mutate a synthetic .clout on them at reveal time, or add a separate "ongoing badge" pass after resolve.
🔄 Angela & Bishop — Need Real Accumulation
  • Angela fires at reveal and counts prior cards already in zone — works for the turn she's played, but does NOT accumulate on subsequent turns when new cards land there.
  • Bishop similarly fires at reveal and counts plays this turn. Real Snap behavior: Bishop gains +1 each time ANY card is played, across all future turns.
  • Fix: maintain a per-card accumulator in game state (e.g. card._angelaAccum) and increment it inside endTurnResolve whenever a card lands in the same zone.
🖱️ Activate UI — Not Yet Built
  • Black Widow (Fred Juggs) — Activate ability: needs a button that appears on the card while it's in a zone, visible during the player's turn. Tapping it should add a Widow's Bite to the opponent's hand.
  • Cloak (Souvenir Cheeseburger) — On Reveal grants a move window next turn. Needs a turn-state flag (zone._cloakTurn) and a UI indicator showing the window is open.
  • Pattern: add an activatable flag to card def; Zone renders an Activate button when the card is in play and it's the player's turn.
🧬 High Evolutionary — Game Start Hook Missing
  • Eggbert (High Evolutionary) — currently a no-op on reveal. Real ability: Game Start, unlock hidden abilities on cards with no written ability text.
  • Implementation path: add a gameStartEffects(state) function called from initGame(). If High Evolutionary is in the deck, iterate SPREADSHEET_CARDS for cards with a hidden ability map (define a HE_ABILITIES const) and set them on those card objects before the game starts.
  • Cards that would need HE abilities defined: Abomination, Cyclops, Hulk, Misty Knight, Shocker, Thing, Wasp (from Snap pool).
