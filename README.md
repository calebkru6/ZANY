# ZANY 🃏
### Interdimensional Card Battles

A browser-based card game built for a group of friends. Inspired by Marvel Snap — play cards across 3 locations over 6 turns, trigger wild abilities, and outscore your opponent to win.

---

## What is this?

ZANY is a two-player card game where you face off against an AI opponent. Each of the 77 cards is a real person from the friend group, given a Marvel Snap-style ability. Cards have names like "Detective Scrotum", "Bonald Brum", and "Pedro Pascal as Fidel Castro."

The game is fully playable in the browser — no downloads, no accounts, no backend.

---

## How to play

1. Pick a deck (or go random)
2. Each turn you get energy equal to the turn number (1 on turn 1, 6 on turn 6)
3. Drag cards from your hand onto one of the 3 locations
4. Hit **End Turn** — both sides reveal their cards and abilities fire
5. After 6 turns, whoever wins 2 of 3 locations wins the game

**Locations** each have an ability that affects play. **Cards** have On Reveal abilities (trigger when flipped) or Ongoing abilities (always active).

You can drag a card you just played back to your hand, or move it to a different location — as long as you haven't ended the turn yet.

## Project structure

```
src/
├── App.jsx              ← Root: CSS injection, card storage, screen routing
├── constants.js         ← TURNS=6, MAX_PER_SIDE=4, HAND_SIZE=4, storage keys
├── styles/globalStyles.js  ← All CSS as a JS string
├── hooks/useTilt.js     ← 3D card tilt effect
├── game/                ← Pure logic (no React)
│   ├── zones.js         ← Location definitions
│   ├── cardImages.js    ← Image URLs (c001–c077)
│   ├── cardData.js      ← All 77 card definitions
│   ├── snapHelpers.js   ← Move/destroy helper functions
│   ├── snapHandlers.js  ← Per-card ability handlers
│   └── gameLogic.js     ← Game state, turns, scoring
├── components/          ← Reusable UI pieces
└── screens/             ← Full page views
```
